# Portfolio di S. M.

Portfolio personale di UX/UI e Web Design, con progetti
di ricerca, accessibilità, design inclusivo e comunicazione visiva.

## Sito online

https://interface-design-projects.github.io/portfolio/index-it.html

## Tecnologie

- HTML5
- CSS3
- Sass / SCSS
- Bootstrap 5.3
- Git e GitHub
- GitHub Pages

## Modulo di contatto

Il modulo utilizza Google Apps Script come servizio esterno per registrare le richieste in un foglio Google Sheets privato.

Il backend è gestito separatamente dal repository del portfolio.
